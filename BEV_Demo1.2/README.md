# Generated AI Art Detector (thesis demo)

Streamlit proof of concept matching the v14 notebooks (LFAB v4).

1. Copy `mobilenet_lfab_model.pth` and `efficientnet_lfab_model.pth` from Notebooks 2 and 3 into `weights/`.
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

`model_def.py` is copied from Notebook 4. If you change LFAB / ProposedAIDetector in the notebooks, re-copy it.
